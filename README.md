# Python Development Internship

## About the Internship

This repository contains the tasks and projects completed as part of my Python Development Internship at Sysslan IT Solutions.

The internship focuses on developing practical Python programming skills through logic building, file handling, automation, and beginner-level real-world projects.

## Technologies Used

- Python 3
- File Handling
- Lists and Dictionaries
- Loops and Conditional Statements
- Object-oriented programming concepts
- CSV and JSON
- NumPy concepts are not required for these tasks.
- Requests and BeautifulSoup
- OS and Shutil modules

## Internship Tasks

### Level 1 – Basic Logic and Structured Thinking
- Display a 3×3 grid.
- Search for a number in a grid.
- Calculate the sum of each row.
- Check whether all numbers are unique.

### Level 2 – Core Python Programs
- Email validation.
- Random password generator.
- Character and word counter.
- Fibonacci sequence generator.

### Level 3 – File Handling and Simple Automation
- Record management using lists and dictionaries.
- Save and retrieve records using JSON.
- Read files line by line.
- Log system using date and time.

### Level 4 – Beginner Automation and Data Handling
- Automatic file organizer.
- Student report generator.
- Daily task manager.
- Numeric data analysis from a file.

### Level 5 – Introduction to Real-World Python Projects
- Web scraping using BeautifulSoup.
- CSV file reader.
- Automated folder backup.
- Personal utility tool.

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Navigate to the required level folder.
5. Run the Python file using:

```bash
python filename.py
```

For web scraping, install the required libraries:

```bash
pip install requests beautifulsoup4
```
